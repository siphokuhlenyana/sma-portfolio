# Siphokuhle Nyana Portfolio

A responsive developer portfolio for Siphokuhle Nyana, an aspiring software engineer focused on full-stack development, thoughtful interfaces, and practical problem solving.

## Overview

The portfolio presents:

- About Me and downloadable resume
- Technical skills with animated progress bars
- Soft skills and tools
- Education and learning path
- Projects with live previews and GitHub links
- Testimonials
- Contact form and social links

## Featured Projects

- UI/UX & Scrum
- Vue-Portfolio
- CampusMate
- Swegga
- Light Novels
- WeatherWise App
- Order Apps
- MiMo Hub

Project cards open a modal with a short description, a live project link where available, and a code repository link.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts: Space Grotesk and DM Mono
- Formspree for contact form submissions

No frameworks or build tools are required.

## Run Locally

From the project directory, start a local static server:

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000) in a browser.

Stop the server with `Ctrl+C`.

## Project Structure

```text
.
├── index.html   # Portfolio markup and interactive JavaScript
├── style.css    # Responsive layout, theme, animations, and components
└── README.md    # Project documentation
```

## Responsive Design

The layout adapts across desktop, tablet, and mobile screens. It includes a collapsible mobile navigation menu, responsive project and skills grids, flexible contact layouts, and reduced-motion support for users who prefer less animation.

## Deployment

This is a static website and can be deployed using GitHub Pages, Netlify, Vercel, or any static hosting provider. Upload or connect the repository and use the project root as the publish directory.
